What the project does

The project turns code risk signals into an interpretable map of vulnerabilities, risky functions, and software-development patterns.

🧭

Maps risk signals

Converts code-level indicators into ranked vulnerability categories so patterns are easier to compare across repositories or generated code.

🧪

Supports research

Frames AI-assisted coding as an empirical security question by comparing outputs against known weakness classes and risky code structures.

📊

Generates reports

Produces readable summaries that can become GitHub Pages reports, class demos, or project documentation.

Analysis workflow

A simple pipeline for studying where AI-generated and human-written code may introduce security risk.

Inputs

  • GitHub repositories
  • Web targets
  • CWE categories
  • Dangerous function patterns
  • Ranked risk scores
1

Collect source material

Pull code or webpage content from the selected target and prepare it for scanning.

2

Scan for risk indicators

Match content against vulnerability keywords and high-risk function patterns such as unsafe string handling, command execution, and memory operations.

3

Aggregate findings

Group repeated findings by vulnerability type and compute a score for each category.

4

Communicate results

Present the most important findings in a clean website, report, or project dashboard.
